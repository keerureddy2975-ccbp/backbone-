Village Farm Labour Connect

గ్రామ వ్యవసాయ కూలీల అనుసంధానం

All-in-One Standalone Single-File Responsive Web Application

🎯 Problem Statement & Rural Context

In rural agricultural areas, smallholder farmers often face acute labour shortages during peak harvesting and transplanting seasons. Concurrently, village agricultural labourers lack direct visibility into daily wage opportunities in nearby villages, making them dependent on commission-charging middle agents (maistries) who reduce their daily earnings.

Village Farm Labour Connect solves this problem by directly connecting local farmers and agricultural labourers through a modern, mobile-friendly interface designed specifically for rural citizens with basic smartphone literacy.

💻 Technical Architecture (Single File Design)

  • Format: 100% self-contained in a single file: index.html
  • Styling: Embedded in <style> tag in <head>
  • Logic: Embedded in <script> before </body>
  • Data Layer: Browser localStorage (for zero-setup student prototype evaluation)
  • Bilingual Engine: Full English & Telugu (తెలుగు) translation dictionary with real-time UI toggling
  • Privacy: Phone number masking algorithm with mutual match unlocking

🧪 Step-by-Step Viva Testing Walkthrough

  1. Language Switch: Click the top button "🌐 తెలుగు (Telugu)" to toggle all text into Telugu, and toggle back to English.
  2. Testing as a Labourer: Click "🌾 Test as Labourer (Lakshmi Devi)" in the yellow bar. Navigate to Find Farm Work, filter by village, and click "Express Interest" on an open job. Check My Work Requests.
  3. Testing as a Farmer: Click "🚜 Test as Farmer (Venkata Rao)". Go to My Posted Jobs, review the applicant and click "✓ Accept". Notice that the labourer's direct contact number is unlocked!
  4. Posting a New Job: Click Post a Job, fill in the form (e.g. Chilli Harvesting, ₹700 wage, 5 workers), and submit. Verify that it appears live in the public listings.
  5. Admin Portal: Click "🛡️ Test as Admin". Review registered users and jobs, or click Reset Sample Demo Data to restore pristine sample records.
